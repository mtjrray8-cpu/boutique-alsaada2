متجر إلكتروني عربي بواجهة عصرية (RTL) مصمم بـ React + Tailwind CSS.

## ✨ المميزات
- تصميم داكن فاخر بلمسات ذهبية ووردية
- واجهة عربية كاملة (RTL)
- 8 أقسام للمنتجات
- سلة مشتريات + مفضلة
- صفحة تفاصيل منتج مع تبويبات
- نظام دفع متعدد الخطوات
- صفحة حساب المستخدم
- أسئلة شائعة
