# بوتيك السعادة — نسخة HTML قابلة للنشر على GitHub Pages

## الملفات
- `index.html`: واجهة المتجر العربية RTL مع التصميم الأسود والذهبي والوردي.
- `admin.html`: لوحة إدارة المنتجات والأقسام والطلبات والعروض وإعدادات الواجهة والنسخ الاحتياطي.
- `.github/workflows/pages.yml`: نشر تلقائي على GitHub Pages عند كل تحديث للفرع `main`.

## المعاينة محلياً
افتح `index.html` في المتصفح. افتح `admin.html` لإدارة المنتجات. يفضّل تشغيل المشروع عبر خادم محلي بسيط بدلاً من فتح الملفات مباشرة، لكن لا توجد مكتبات أو عملية بناء مطلوبة.

## النشر على GitHub Pages
1. أنشئ مستودع GitHub جديداً باسم `boutique-alsaada`.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، وليس المجلد الأب.
3. من إعدادات المستودع افتح **Pages** واختر **GitHub Actions** كمصدر للنشر.
4. بعد اكتمال مهمة Actions سيظهر رابط الموقع في صفحة Pages، عادةً بالشكل:
   `https://USERNAME.github.io/boutique-alsaada/`
5. لوحة الإدارة ستكون على:
   `https://USERNAME.github.io/boutique-alsaada/admin.html`

## تنبيه تقني مهم
هذه نسخة Frontend ثابتة متوافقة مع GitHub Pages. تحفظ لوحة الإدارة المنتجات والأقسام والإعدادات والطلبات في `localStorage` الخاص بالمتصفح. لذلك:
- التغييرات تظهر على المتجر عند فتحه من المتصفح نفسه وعلى النطاق نفسه.
- لا تتم مزامنة البيانات تلقائياً بين أجهزة العملاء أو متصفحاتهم.
- GitHub Pages لا يشغّل PHP ولا MySQL ولا يوفر خادماً لمعالجة الطلبات.
- لا تستخدم هذه النسخة لتخزين بيانات شخصية أو طلبات حقيقية أو كلمات مرور إدارية.

للتشغيل التجاري الحقيقي مع لوحة تحكم مشتركة لكل الزوار، يلزم نشر Backend مثل PHP + MySQL على استضافة تدعم PHP (مثل InfinityFree أو استضافة مماثلة)، مع إبقاء واجهات المتجر HTML كما هي وربطها بواجهات API. لا تضع بيانات اتصال قاعدة البيانات أو كلمات مرور داخل ملفات HTML أو JavaScript.

## الوظائف الموجودة في النسخة
- تصفح الأقسام والمنتجات والبحث.
- إضافة للسلة وتغيير الكميات والحذف والمفضلة.
- إتمام طلب تجريبي وحفظه محلياً ومتابعة الطلبات.
- لوحة تحكم لإضافة وتعديل وحذف وإخفاء المنتجات والأقسام.
- رفع صور مضغوطة للمنتجات والأقسام والبنر.
- تعديل اسم المتجر ونصوص البنر ورقم واتساب والبريد.
- تغيير حالة الطلب والبحث عنه وحذفه.
- تصدير واستيراد نسخة احتياطية JSON.
