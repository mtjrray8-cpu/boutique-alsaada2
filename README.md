# بوتيك السعادة — متجر PHP و MySQL

## محتويات المشروع
- واجهة متجر عربية متجاوبة مع الجوال، بتصميم أسود وذهبي.
- المنتجات والأقسام والسلة وإتمام الطلب.
- لوحة تحكم للمنتجات والطلبات وإعدادات اسم المتجر والبانر وخلفية الصفحات.
- جلسات للسلة، كلمات مرور مشفرة، واستعلامات PDO محضّرة.

## متطلبات التشغيل
- PHP 8.0 أو أحدث مع PDO MySQL و Fileinfo.
- قاعدة بيانات MySQL أو MariaDB.
- استضافة تدعم PHP (مثل InfinityFree). GitHub مستودع لحفظ الكود وليس استضافة PHP.

## التثبيت على الاستضافة
1. أنشئ قاعدة MySQL من لوحة الاستضافة.
2. افتح phpMyAdmin واستورد `database.sql`.
3. عدّل `config.php` وضع اسم قاعدة البيانات والمستخدم وكلمة المرور واسم المضيف كما تعرضها الاستضافة.
4. ارفع محتويات هذا المجلد إلى `htdocs` أو مجلد الموقع العام.
5. افتح `https://رابط-متجرك/setup.php` وأنشئ اسم مدير وكلمة مرور قوية (10 أحرف على الأقل).
6. بعد إنشاء المدير، احذف `setup.php` من الاستضافة فوراً.
7. افتح `/admin/login.php` وسجّل الدخول.

## الرفع إلى GitHub من الجوال
1. أنشئ مستودعاً جديداً في GitHub.
2. ارفع ملفات المشروع، لكن لا ترفع `config.php` الحقيقي إذا وضعت فيه بيانات قاعدة البيانات. الأفضل الاحتفاظ ببيانات الإنتاج خارج المستودع، أو رفع نسخة إعدادات بلا كلمات مرور.
3. لا تضع كلمات مرور قاعدة البيانات أو بيانات العملاء داخل GitHub.
4. GitHub Pages لا يشغّل PHP ولا MySQL؛ استخدم الاستضافة لتشغيل المتجر.

## ملاحظات
- العملة الافتراضية ر.س ورقم واتساب الافتراضي في `config.php` هو الرقم الذي سبق تحديده للمحل؛ عدّله عند الحاجة.
- لا توجد منتجات تجريبية جاهزة؛ أضف المنتجات وصورها من لوحة التحكم.
- اختبر إنشاء طلب وتحديث حالته قبل استقبال العملاء.
